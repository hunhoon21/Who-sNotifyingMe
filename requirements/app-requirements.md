# Who's Notifying Me - 요구사항 명세서

> 작성일: 2026-01-12
> 버전: 1.0 (MVP)

## 핵심 목적

**"불필요한 알림을 식별하고 끄도록 도와서, 중요한 알림을 놓치지 않게 하는 앱"**

### 문제 정의
- 너무 많은 앱 알림으로 인한 알림 과부하
- 중요한 알림을 놓치는 상황 발생
- 어떤 앱이 알림을 많이 보내는지 파악 어려움

### 해결 방안
- 앱별 알림 통계를 시각적으로 제공
- "알림 스팸" 앱을 쉽게 식별
- iOS 설정으로 빠르게 이동하여 끄기 지원

---

## Original Requirement

"Who's Notifying Me. 라는 제목의 앱으로 나에게 오는 알람들을 시각적으로 분석해주고 끌 것들은 끄고 앱에 대한 통계도 내고, 더 나아가 나에게 오는 알람들의 특징이나 종류들을 분석해서 알려주는 앱을 만드려고 해."

## 기술 명세

### 데이터 수집
- **방식**: Screen Time API (DeviceActivity Framework)
- **iOS 제한**: 다른 앱 알림 직접 접근 불가
- **수집 데이터**: 앱별 알림 횟수, 시간대별 분포

### 플랫폼 요구사항
- **최소 iOS 버전**: 17.0
- **필요 권한**:
  - Screen Time (Family Controls)
  - 알림 권한 (자체 앱 알림용)

### UI/UX
- **스타일**: 미니멀/클린 (Apple 기본 스타일)
- **프레임워크**: SwiftUI
- **차트**: Swift Charts

### 아키텍처
- **패턴**: MVVM + Clean Architecture
- **데이터 저장**: Core Data (로컬)
- **언어**: Swift 5.9+

## 성공 기준 (Definition of Done)

### 기능적 요구사항
- [ ] Screen Time 권한 요청 플로우 완성
- [ ] Screen Time API로 앱별 알림 데이터 수집
- [ ] 대시보드에 오늘/주간 알림 수 표시
- [ ] 앱별 알림 횟수 리스트 표시
- [ ] 시간대별 차트 렌더링
- [ ] 일별 트렌드 차트 렌더링
- [ ] 앱 상세 화면에서 "설정에서 끄기" 버튼 동작
- [ ] 한국어/영어 로컬라이제이션

### 비기능적 요구사항
- [ ] 앱 실행 시 2초 이내 대시보드 로딩
- [ ] 차트 렌더링 시 버벅임 없음
- [ ] iOS 17.0+ 지원

## 결정 사항 요약

| 항목 | 결정 | 이유 |
|------|------|------|
| 데이터 수집 | Screen Time API | iOS 제한으로 유일한 합법적 방법 |
| 분석 수준 | 기본 통계 | MVP 단순화, AI는 추후 |
| 알림 관리 | iOS 설정 바로가기 | 직접 제어 불가, UX 최적화 |
| UI 스타일 | 미니멀/클린 | Apple 가이드라인 준수 |
| 위젯 | 추후 개발 | MVP 범위 축소 |
| 수익 모델 | 무료 시작 | 사용자 확보 후 프리미엄 전환 |
| 언어 | 한국어 + 영어 | 글로벌 출시 대비 |
